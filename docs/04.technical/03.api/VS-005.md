# VS-005 API Design - Subtitle OCR, Masking & Multi-Tab Workspace

Owner: Dev / TechLead  
Status: Draft / Approved for Implementation  
Slice ID: `VS-005`

## 1. Danh sách API Endpoints Mới

| API ID | Method | Endpoint | Mô tả | Request Body / Params | Response Code |
|---|---|---|---|---|---|
| `API-004` | `POST` | `/api/translate-ocr` | Khởi chạy pipeline OCR Subtitle Tracking, Masking & Dubbing | `TranslationOCRRequest` (JSON) | 200, 400 |
| `API-005` | `GET` | `/api/subtitles/{task_id}` | Tải file phụ đề SubRip format (.srt) | `task_id` (Path param) | 200, 404 |
| `API-006` | `POST` | `/api/tts-free` | Đọc văn bản tự do thành file MP3 qua Edge-TTS | `text`, `voice`, `rate` (JSON) | 200, 400 |
| `API-007` | `POST` | `/api/video-preview-info` | Bóc tách metadata và trích xuất frame mẫu cho canvas | `url` hoặc multipart file upload | 200, 400 |

---

## 2. Chi tiết Endpoints

### 2.1. `POST /api/translate-ocr` (`API-004`)
- **Mục đích:** Khởi chạy tiến trình bóc chữ bằng RapidOCR, che sub cũ và in sub tiếng Việt.
- **Request Body (JSON):**
```json
{
  "url": "https://www.bilibili.com/video/BV1xx411c7mD",
  "voice": "female_hoaimy",
  "source_lang": "Chinese",
  "bg_volume": 0.15,
  "tts_volume": 1.0,
  "bilibili_cookie": "SESSDATA=xxxx...",
  "mask_box": {
    "x": 10.0,
    "y": 80.0,
    "w": 80.0,
    "h": 12.0,
    "enabled": true,
    "style": "blur"
  },
  "sub_box": {
    "x": 10.0,
    "y": 80.0,
    "w": 80.0,
    "h": 12.0,
    "locked": true
  },
  "sub_styling": {
    "font_size": 28,
    "font_color": "#ffffff",
    "stroke_color": "#000000",
    "stroke_width": 2
  }
}
```
- **Response (200 OK):**
```json
{
  "task_id": "9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6d",
  "status": "pending",
  "mode": "ocr"
}
```

---

### 2.2. `GET /api/subtitles/{task_id}` (`API-005`)
- **Mục đích:** Cung cấp tệp phụ đề rời định dạng `.srt` chuẩn UTF-8.
- **Response Headers:**
  - `Content-Type`: `text/plain; charset=utf-8`
  - `Content-Disposition`: `attachment; filename="subtitles_9b1deb4d.srt"`
- **Response Body (Sample .srt):**
```text
1
00:00:01,200 --> 00:00:03,500
Xin chào tất cả các bạn đã quay trở lại.

2
00:00:03,800 --> 00:00:06,100
Hôm nay chúng ta sẽ cùng khám phá công nghệ mới.
```

---

### 2.3. `POST /api/tts-free` (`API-006`)
- **Mục đích:** Phục vụ công cụ Text-to-Speech Studio tại Tab 3 (Đọc văn bản tự do).
- **Request Body:**
```json
{
  "text": "Đoạn văn bản tiếng Việt cần đọc thử...",
  "voice": "female_hoaimy",
  "rate": "+0%"
}
```
- **Response (200 OK):** Trả về luồng âm thanh trực tiếp (`audio/mpeg`).

- Endpoint gốc `POST /api/translate` (`API-001`) giữ nguyên 100% contracts để phục vụ Tab 2 (Video KHÔNG CÓ Sub - Whisper STT). Các tham số `sub_box` và `sub_styling` được bổ sung dạng Optional (mặc định căn giữa đáy nếu client không truyền).
