# VS-006 API Specification - Video Logo & Watermark Overlay

Owner: TechLead / Dev  
Status: Approved  

## 1. Tải lên tệp Logo dự án (`API-019`)

- **Method:** `POST`
- **Endpoint:** `/api/project/{project_id}/logo`
- **Content-Type:** `multipart/form-data`
- **Parameters:**
  - `project_id` (path, string): Mã định danh dự án UUID.
  - `file` (form, UploadFile): Tệp hình ảnh logo (.png, .jpg, .jpeg, .webp, .svg, .bmp).

### Response (200 OK):
```json
{
  "status": "ok",
  "logo_url": "/api/project/21fab9c8-9941-4ab2-8e71-a7361007a65a/logo",
  "filename": "watermark_channel.png",
  "logo_box": {
    "enabled": true,
    "image_path": "c:/project/tool-translate/app/projects/21fab9c8-9941-4ab2-8e71-a7361007a65a/logo.png",
    "filename": "watermark_channel.png",
    "logo_url": "/api/project/21fab9c8-9941-4ab2-8e71-a7361007a65a/logo",
    "x": 80.0,
    "y": 5.0,
    "w": 18.0,
    "h": 12.0,
    "opacity": 1.0,
    "keep_aspect": true
  }
}
```

### Error Responses:
- `400 Bad Request`: Định dạng ảnh không được hỗ trợ.
- `404 Not Found`: Dự án không tồn tại.

---

## 2. Stream tệp Logo dự án (`API-020`)

- **Method:** `GET`
- **Endpoint:** `/api/project/{project_id}/logo`
- **Parameters:**
  - `project_id` (path, string): Mã định danh dự án UUID.

### Response (200 OK):
- **Content-Type:** `image/png` | `image/jpeg` | `image/webp` | `image/svg+xml`
- **Body:** Binary image stream.

---
