# VS-002 Requirements - Web Interface & Task Monitoring

Owner: BA / Design  
Status: Baseline Implemented (Phase 1)

## Scope
Cung cấp giao diện web cục bộ cho người dùng thao tác nhập liệu, theo dõi trạng thái tiến độ và tải kết quả.

## Functional Requirements

| Req ID | Tiêu đề | Mô tả nghiệp vụ | Mức độ ưu tiên | Trạng thái |
|---|---|---|---|---|
| `REQ-007` | Form nhập thông tin dịch | Cho phép nhập URL Bilibili, chọn giọng đọc (Hoài My, Nam Minh, TikTok), ngôn ngữ nguồn, cookie SESSDATA | High | Implemented |
| `REQ-008` | Thanh tiến độ thời gian thực | Polling `/api/status/{task_id}` mỗi 2 giây, cập nhật thanh progress bar và hiển thị thông điệp tiến trình | High | Implemented |
| `REQ-009` | Tải xuống video thành phẩm | Hiển thị nút "Tải video" và trình phát video xem trước khi pipeline hoàn tất | High | Implemented |

## Non-functional Requirements
- **Giao diện:** Tương thích tốt trên màn hình Desktop và Laptop, giao diện tối hiện đại, tương tác mượt mà.
- **Phản hồi:** Trạng thái lỗi (HTTP 412, URL sai định dạng) phải được hiển thị rõ ràng trên giao diện.
