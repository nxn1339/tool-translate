# Design System - Design Tokens & Visual Specs

## 1. Bảng màu (Color Palette)
- **Primary Accent:** `#6366f1` (Indigo Neon)
- **Secondary Accent:** `#ec4899` (Pink Vibrant)
- **Background Dark:** `#0f172a` (Slate 900)
- **Surface Card:** `#1e293b` (Slate 800)
- **Border / Divider:** `#334155` (Slate 700)
- **Text Primary:** `#f8fafc` (Slate 50)
- **Text Secondary:** `#94a3b8` (Slate 400)
- **Success:** `#10b981` (Emerald 500)
- **Error:** `#ef4444` (Red 500)

## 2. Typography
- Font Family: `'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`
- Base Size: `16px`
- Headings: `h1: 2rem (bold)`, `h2: 1.5rem (semibold)`, `h3: 1.25rem (medium)`

## 3. Hiệu ứng giao diện (UI Effects)
- Glassmorphism: Background bán trong suốt kèm `backdrop-filter: blur(12px)`.
- Border Radius: Cards `16px`, Inputs & Buttons `10px`.
- Transition: `all 0.25s cubic-bezier(0.4, 0, 0.2, 1)`.
