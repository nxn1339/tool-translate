## 1. Nguyên lý hoạt động của Prototype Kéo - Thả Bounding Box

Bộ khung kéo thả được xây dựng bằng CSS Absolute Positioning kết hợp với JavaScript Event Listeners (`mousedown`, `mousemove`, `mouseup` / `touchstart`, `touchmove`, `touchend`):
1. **Tọa độ chuẩn hóa (% Native Coordinates):**
   * Mọi vị trí và kích thước của Khung Đỏ (Mask) và Khung Xanh (Subtitle) được tính theo tỷ lệ phần trăm so với kích thước thẻ video (`box.left = (e.clientX - rect.left) / rect.width * 100`).
   * Khi gửi payload sang backend, hệ thống gửi object:
   ```json
   {
     "mask_box": { "x": 10.5, "y": 80.2, "w": 79.0, "h": 12.5, "enabled": true, "style": "blur" },
     "sub_box": { "x": 10.5, "y": 80.2, "w": 79.0, "h": 12.5, "locked": true }
   }
   ```
2. **Khống chế biên (Boundary Clamping):**
   * Tọa độ `X + Width <= 100%` và `Y + Height <= 100%`.
   * Chiều rộng tối thiểu `Width >= 5%`, chiều cao tối thiểu `Height >= 3%`.
