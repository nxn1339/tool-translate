# Recommended Skills Catalog - Danh mục kỹ năng

## 1. Kỹ năng nội bộ dự án (.agents/skills/)

- `output-docs-standard`: Quy chuẩn đặt tên file, slice source-of-truth, UTF-8 tiếng Việt và Single-File Multi-Phase.
- `ba-workflow`: Phân tích nghiệp vụ, viết Requirement, User Story, Business Rule và Acceptance Criteria.
- `dev-workflow`: Thiết kế kỹ thuật, API contract, quy chuẩn code Python/FastAPI và dev task list.
- `design-workflow`: Thiết kế UI/UX, tokens, flow và layout giao diện.
- `test-workflow`: Lập Test Plan, Test Cases, Bug Report và ma trận kiểm thử.
- `pm-task-assignment`: Quản lý danh sách task (`TASK-XXX`, `DEV-XXX`), WBS và lộ trình.
- `docs-consistency-review`: Quét kiểm toán tự động tính nhất quán giữa Docs, Code và Test.
- `change-request-triage`: Tiếp nhận và phân loại Change Request.
- `techlead-pr-review`: Đánh giá mã nguồn và thiết kế kỹ thuật trước khi merge.
- `github-pr-link-generator`: Sinh link tạo PR tự động trên GitHub.

## 2. Kỹ năng Superpowers tích hợp
- `superpowers:test-driven-development`: TDD cho các tính năng và bugfix.
- `superpowers:systematic-debugging`: Điều tra nguyên nhân gốc rễ (root cause) khi gặp lỗi.
- `superpowers:verification-before-completion`: Kiểm chứng và lưu evidence trước khi hoàn thành công việc.
